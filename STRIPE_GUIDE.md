🔍 STRIPE - Como Encontrar as API Keys (Passo a Passo)
==================================================

📋 GUIA VISUAL - Siga exatamente estas etapas:

1️⃣ ACESSE: https://dashboard.stripe.com
   ✅ Faça login com sua conta

2️⃣ MENU LATERAL ESQUERDO:
   👀 Procure por "Developers" (Desenvolvedores)
   🖱️ CLIQUE em "Developers"

3️⃣ SUBMENU "Developers":
   👀 Procure por "API keys" 
   🖱️ CLIQUE em "API keys"

4️⃣ PÁGINA DAS CHAVES:
   Você verá duas seções:

   📊 STANDARD KEYS (Use estas):
   ▶️ Publishable key: pk_test_xxxxx... [👁️ Reveal] ← CLIQUE em "Reveal"
   ▶️ Secret key: sk_test_xxxxx... [👁️ Reveal] ← CLIQUE em "Reveal"

5️⃣ COPIAR AS CHAVES:
   📋 Publishable key (começa com pk_test_)
   📋 Secret key (começa com sk_test_)

💡 DICA: Se não conseguir ver "API keys", tente:
   - Atualizar a página
   - Verificar se está logado corretamente
   - Olhar no menu "Settings" → "API keys"

🎯 RESULTADO ESPERADO:
   Duas chaves que começam com:
   - pk_test_xxxxxxxxxxxxx
   - sk_test_xxxxxxxxxxxxx

📞 ME DIGA: Consegue ver o menu "Developers" no lado esquerdo?
